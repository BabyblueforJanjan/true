# 🤖 Claude ช่วยติว Google Form

Chrome extension สำหรับ **แบบฝึกหัด / quiz ฝึกซ้อม** ใน Google Form
กดปุ่มเดียว → Claude อ่านทุกข้อในหน้า → แสดง **คำตอบพร้อมคำอธิบาย** → เลือกกรอกลงฟอร์มทีละข้อหรือทั้งหมด

> ⚠️ ใช้กับแบบฝึกหัดที่ไม่นับคะแนนเท่านั้น ไม่ใช้กับข้อสอบหรือแบบทดสอบที่ใช้วัดผลจริง

## ติดตั้ง
1. เปิด Chrome ไปที่ `chrome://extensions`
2. เปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** → เลือกโฟลเดอร์ `google-form-helper`
4. คลิกไอคอน extension → ใส่ Anthropic API key ในช่องด้านล่าง → กด **บันทึก** (สร้างที่ [console.anthropic.com](https://console.anthropic.com/settings/keys))

## วิธีใช้
1. เปิด Google Form แบบฝึกหัด
2. คลิกไอคอน extension → กด **ให้ Claude ช่วยทำฟอร์มนี้**
3. ในกล่องมุมขวา
   - **กรอก**: กรอกคำตอบทุกข้อลงฟอร์ม
   - **ดูคำอธิบาย ▾**: เปิดดูคำตอบและเหตุผลทีละข้อ (กรอกทีละข้อได้)
4. ตรวจทานก่อนกดส่งเอง (extension ไม่กดส่งให้)

## ค่าใช้จ่าย
ใช้โมเดล **Claude Haiku 5.5** ซึ่งเร็วและถูกมาก แบบฝึกหัด 20 ข้อตกครั้งละไม่ถึง 10 สตางค์ (ต้องเติมเครดิต API ที่ console.anthropic.com ก่อน)

## รองรับ
| ชนิดคำถาม | แสดงคำตอบ | กรอกอัตโนมัติ |
|---|---|---|
| เลือกตอบ (ข้อเดียว) | ✅ | ✅ |
| ช่องทำเครื่องหมาย (หลายข้อ) | ✅ | ✅ |
| คำตอบสั้น / ย่อหน้า | ✅ | ✅ |
| Dropdown | ✅ | ❌ เลือกเองตามคำตอบ |
| อัปโหลดไฟล์, ตารางกริด, รูปภาพในคำถาม | ❌ | ❌ |

ข้อที่ถามข้อมูลส่วนตัว (ชื่อ เลขที่ อีเมล) Claude จะข้ามไป ไม่กรอกให้
ถ้าฟอร์มมีหลายหน้า ให้กดปุ่มใหม่ทุกครั้งที่ขึ้นหน้าถัดไป

## ไฟล์
```
google-form-helper/
├── manifest.json   # ตั้งค่า extension (Manifest V3)
├── popup.html/js   # ปุ่มหลัก
├── content.js/css  # อ่านคำถาม แสดงคำตอบ กรอกฟอร์ม
├── background.js   # เรียก Claude API (claude-haiku-5-5)
└── options.html/js # ตั้งค่า API key
```
